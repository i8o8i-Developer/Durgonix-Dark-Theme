## About The Project

Durgonix Dark Theme Is A Carefully Crafted Visual Experience Designed For Developers Who Demand Both Uncompromising Aesthetics And Maximum Readability. Inspired By Classic Terminal Palettes And Cyberpunk Matrix Aesthetics, This Theme Delivers:

- **Ultra-High Contrast Canvas**: Deep Obsidian Black (`#0B0C0E`) Minimizes Eye Strain During Long Coding Sessions.
- **Neon Hacker-Green Accents**: Electric `#00FF41` Accents Illuminate Active Tabs, Cursors, Selection Highlights, And Focus Borders.
- **Vibrant Multi-Language Palette**: Rich, Saturated Colors For Keywords, Functions, Types, Classes, And Template Interpolations.
- **Full Semantic Highlighting Engine**: Native Language Server Protocol (LSP) Token Differentiation For Modern IDEs.
- **Bracket Pair Rainbow Colorization**: Six-Tier Neon Gradient Guiding Complex Nested Logic.

## Quick Install

### Method 1: Install From VS Code Marketplace
```bash
code --install-extension i8o8i.durgonix-dark-theme
```

### Method 2: Install From Local Package (VSIX)
```bash
code --install-extension ./durgonix-dark-theme-1.1.1.vsix
```

---

## Recommended Settings

For The Ultimate Cyberpunk Development Experience, Add The Following Configuration To Your VS Code `settings.json`:

```json
{
  "workbench.colorTheme": "Durgonix Dark",
  "editor.semanticHighlighting.enabled": true,
  "editor.bracketPairColorization.enabled": true,
  "editor.guides.bracketPairs": "active",
  "editor.cursorBlinking": "smooth",
  "editor.cursorSmoothCaretAnimation": "on",
  "workbench.iconTheme": "vscode-icons"
}
```

---

## Customization

You Can Fine-Tune Specific UI Surfaces Using `workbench.colorCustomizations` In Your User Settings:

```json
"workbench.colorCustomizations": {
  "[Durgonix Dark]": {
    "tab.activeBorderTop": "#00FF41",
    "badge.background": "#007A2E",
    "badge.foreground": "#FFFFFF",
    "statusBar.background": "#050505"
  }
}
```
